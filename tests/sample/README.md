# Self-test sample

This solution exists only to exercise `.github/workflows/dotnet-ci.yml` from
this repo's own `self-test.yml`: one tiny class library and one xUnit test
project with a single passing test, targeting `net8.0`.

It is not a template and not an example service. Keep it as small as possible;
change it only when `dotnet-ci.yml` needs something new exercised.
